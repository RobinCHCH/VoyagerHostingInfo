VoyagerHostingInfrastructure

Encrypted backups for a shared web gateway.

VoyagerHostingInfrastructure is a personal operational utility maintained by Robin Cox. It uses rclone and Google Drive to store and retrieve encrypted backups of gateway configuration and HTTPS certificate state for recovery.

How Google Drive is used

The operator explicitly authorises their own Google account. The utility requests the limited drive.file permission to create, retrieve, verify and manage its backup files. It does not request access to the whole Drive, Gmail, contacts or calendars.

Sensitive gateway archives are encrypted before upload. The private recovery key is kept separately by the operator. Google sign-in takes place through Google's authorisation flow; this website never asks for a Google password.

For the owner, not a public sign-up service

This website provides information about the utility. There are no customer accounts, sign-up forms or backup uploads here. The infrastructure source, credentials and backup archives are not published on this site.

Privacy notice Contact the maintainer

Contact issues are public. Do not include credentials, backup contents, private keys or other private information.
