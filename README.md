# VoyagerHostingInfo

Public homepage and privacy notice for the personal VoyagerHostingInfrastructure
gateway backup utility. This repository contains only static website content.

The infrastructure repository, deployment files, credentials, certificate state
and backups are separate and private. Do not add them here.

Published site: https://robinchch.github.io/VoyagerHostingInfo/

GitHub Pages publishes the root of the `main` branch. No custom domain or paid
hosting service is required. No analytics or third-party scripts are included.
